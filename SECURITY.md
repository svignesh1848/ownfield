# Security policy

Please **do not** report security problems in public GitHub issues.

Report privately by either:
- GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting), or
- Email: **hello@ownfield.in** with the subject "Security".

Include what you found, steps to reproduce, and the impact. We aim to reply within 3 working days and to fix confirmed issues as quickly as possible. Please give us reasonable time to fix before any public disclosure, and do not access or change other people's data while testing.

Supported version: the latest `master` branch (what runs at app.ownfield.in).
